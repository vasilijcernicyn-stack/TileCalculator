# Проект: Умный строительный калькулятор плитки (TileCalculator)

Полезная прикладная программа для автоматизации строительных расчётов в помещениях со сложной планировкой.

## 🛠️ Какую проблему решает проект?
Обычные калькуляторы в интернете умеют считать плитку только для идеальных прямоугольных комнат. Если в помещении есть Г-образные повороты, выступы, ниши под батареи или короба для вентиляции — стандартные программы пасуют.

Этот калькулятор решает проблему с помощью **геометрического алгоритма Гаусса (формулы шнурования)**. Пользователь просто обходит комнату по часовой стрелке и вводит параметры углов. Программа сама вычисляет точную площадь любой сложной многоугольной фигуры.

## 🎮 Возможности программы:
* **Интуитивный интерфейс:** Не нужно высчитывать координаты — пользователь просто указывает цифрами направление поворота (1 — направо, 2 — налево) и длину стены.
* **Перфекционизм в выводе:** Программа автоматически форматирует числа, убирая лишние нули в хвосте (например, выводит красивое `0.25 кв.м.` вместо заумного `0.2500`).
* **Автоматический расчёт запаса:** Калькулятор автоматически закладывает 10% на подрезку плитки у сложных стен и округляет итоговый результат в большую сторону до целой штуки.

* Математическая модель: **Алгоритм Гаусса (Surveyor's Area Formula)**
